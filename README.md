# AI 프롬프트 효율성 비교: 주택청약 디스코드 봇

## 프로젝트 소개

AI 코딩 어시스턴트(Claude Code)에게 **동일한 프로젝트**를 **3가지 다른 수준의 프롬프트**로 요청했을 때 결과물이 어떻게 달라지는지 비교하는 실험 프로젝트입니다.

핵심 질문: **`.claude.md`, `AGENTS.md`, `llms.txt` 같은 컨텍스트 파일이 AI와의 소통 효율을 얼마나 높이는가?**

---

## 만들려는 것

**주택청약 정보 디스코드 봇** -- 한국 부동산 청약 정보를 조회하고 알림을 받을 수 있는 디스코드 봇

- Python (discord.py + FastAPI)
- data.go.kr 한국부동산원 청약홈 API 연동
- 신규 분양공고 자동 알림
- 디스코드 명령어로 청약정보/경쟁률 조회

---

## 실험 설계

각 케이스는 **정확히 1번의 프롬프트**만 사용합니다. 추가 지시나 수정 요청 없이, 한 번의 프롬프트로 Claude Code가 무엇을 만들어내는지 비교합니다.

### Case 1: 간단한 프롬프트 (`case1` 브랜치)

- **접근법:** 기본적인 요구사항만 한 문단으로 전달 (~50단어)
- **제공하는 것:** 기술스택 이름, 데이터소스, 핵심 기능 2가지
- **생략하는 것:** 디렉토리 구조, API 엔드포인트, 명령어 목록, 에러처리, 환경변수, 코드 스타일
- **목적:** 최소한의 정보로 AI가 무엇을 유추하고 만들어내는지 확인

### Case 2: 상세한 요구사항 프롬프트 (`case2` 브랜치)

- **접근법:** 기술 스택, API 명세, 디렉토리 구조, 에러 처리까지 상세히 프롬프트에 포함 (~500단어)
- **제공하는 것:** 버전 정보, API 경로/파라미터/응답필드, 명령어 7개 정의, 환경변수, 코드 스타일 규칙
- **생략하는 것:** 없음 (프롬프트 자체에 모든 정보 포함)
- **목적:** 프롬프트 텍스트에 충분한 정보를 담았을 때의 품질 향상 측정

### Case 3: 컨텍스트 파일 + 짧은 프롬프트 (`case3` 브랜치)

- **접근법:** `CLAUDE.md`, `AGENTS.md`, `llms.txt` 파일에 프로젝트 컨텍스트를 사전 배치 후 짧은 프롬프트 전달 (~25단어)
- **사전 준비 파일:**
  - `CLAUDE.md` (~200줄) -- Claude Code 전용 프로젝트 지시서. 기술스택/버전, API 연동, 개발규칙, 에러처리, 패키지 호환성, 개발순서, 특별 주의사항까지 포함.
  - `AGENTS.md` (~120줄) -- AI 코딩 에이전트 범용 컨텍스트. 프로젝트 구조, 코드리뷰 기준, 테스트 작성 규칙, 개발 워크플로우, 코드 품질 기준 포함.
  - `llms.txt` (~60줄) -- LLM 표준 포맷. API 엔드포인트, 문서 링크, 명령어 목록, 핵심 의존성 요약.
- **목적:** 파일 기반 컨텍스트가 프롬프트 효율성을 얼마나 높이는지 측정

## 통제 조건 (동일 환경)

공정한 비교를 위해 **프롬프트/컨텍스트 파일 외의 모든 조건을 동일하게 통제**합니다.

| 통제 변수 | 설정 |
|-----------|------|
| Claude Code 모델 | Claude Opus 4.6 (동일) |
| oh-my-claudecode 플러그인 | 동일 버전, 동일 스킬 활성화 |
| 글로벌 `~/.claude/CLAUDE.md` | 동일 (OMC 오케스트레이션 설정) |
| 운영체제 | macOS Darwin 24.5.0 |
| Python 버전 | 3.12.x |
| 실행 방식 | 새 Claude Code 세션에서 1회 프롬프트 |
| 사후 개입 | 없음 (추가 질문, 수정 요청 금지) |

### 변수 (case별 차이점)

| | Case 1 | Case 2 | Case 3 |
|---|---|---|---|
| 프롬프트 길이 | ~50단어 | ~500단어 | ~25단어 |
| 프로젝트 컨텍스트 파일 | 없음 | 없음 | CLAUDE.md + AGENTS.md + llms.txt |
| 총 컨텍스트 정보량 | 최소 | 프롬프트에 집중 | 파일에 분산 |

## 컨텍스트 파일이란?

| 파일 | 용도 | 읽는 대상 |
|------|------|-----------|
| `CLAUDE.md` | Claude Code 전용 프로젝트 지시서. 세션 시작 시 자동 로드. | Claude Code |
| `AGENTS.md` | AI 코딩 에이전트 범용 표준. 25+ 도구 지원 (Codex, Copilot, Cursor 등). | 모든 AI 코딩 도구 |
| `llms.txt` | LLM을 위한 웹/프로젝트 요약 표준 (`robots.txt`의 LLM 버전). | 모든 LLM |

### 왜 효과적인가?

1. **반복 제거:** 매 세션마다 같은 설명을 반복할 필요 없음
2. **구조화된 정보:** AI가 파싱하기 쉬운 형태로 컨텍스트 제공
3. **자동 로딩:** `CLAUDE.md`는 세션 시작 시 자동으로 읽힘
4. **재사용성:** 파일은 세션 간 유지되어 일관된 결과 보장

## 재현 방법

```bash
# 1. 원하는 케이스 브랜치 체크아웃
git checkout case1  # 또는 case2, case3

# 2. 의존성 설치
pip install -r requirements.txt

# 3. 환경변수 설정
cp .env.example .env
# .env에 DISCORD_TOKEN, DATA_GO_KR_API_KEY 입력

# 4. 테스트 실행
python -m pytest tests/ -v

# 5. 봇 실행
python -m bot.main
```
